# 성과 페이지 시나리오 검토 결과

> 검토일: 2026-04-08  
> 대상: `PerformancePage.tsx`, `GoalsListCards.tsx`, `GoalsKanbanBoard.tsx`, 관련 feature 파일 전체

## 1. 코드에서 직접 수정 완료한 항목

### 1-1. 목표 완료/취소 UI 누락 (Critical)
- **문제:** `goalApi.completeGoal()`, `goalApi.cancelGoal()` API가 존재하지만 UI에서 호출하는 곳이 전혀 없어 목표를 영원히 완료/취소할 수 없었음
- **수정:** 상세 모달에 "완료 처리" / "목표 취소" 버튼 추가, 확인 대화상자 포함
- **조건:** 완료 = `canUpdate && ACTIVE`, 취소 = `canUpdate && (DRAFT || ACTIVE)`

### 1-2. 실적 입력 모달에 목표 정보 미표시
- **문제:** 기준값, 목표값, 현재값, 단위를 모른 채 수치를 입력해야 했음
- **수정:** 모달 상단에 목표명, 기준값/목표값/현재값, 단위 표시 카드 추가

### 1-3. 실적 입력 권한 로직 오류
- **문제:** `canCreate`(목표 생성 권한)를 실적 제출 조건으로 사용. 일반 구성원이 본인 목표에 실적 제출 불가
- **수정:** 본인 소유(`isOwner`) + 상태 `ACTIVE`이면 권한 무관하게 실적 제출 가능하도록 변경 (GoalsListCards, GoalsKanbanBoard, 상세 모달 모두)

### 1-4. 조직 목표 실적 제출 불가
- **문제:** 조직 목표(`ownerType: ORGANIZATION`)는 `ownerId`가 org UUID라 `memberId`와 매칭되지 않아 실적 입력 버튼이 절대 노출되지 않았음
- **수정:** 상세 모달에서 `ownerType === 'ORGANIZATION'`이면 실적 입력 가능하도록 조건 추가

### 1-5. TEXT 입력 유형과 숫자 필드 충돌
- **문제:** `inputType`을 TEXT로 선택해도 "달성 수치"(InputNumber, min=0)가 표시되어 의미적으로 어색
- **수정:** TEXT일 때 라벨을 "달성 결과"로 변경하고 min 제한 제거, 안내 placeholder 추가

### 1-6. 기간 만료 목표 경고 없음
- **문제:** ACTIVE인데 종료일이 지난 목표에 아무 경고 표시 없음
- **수정:** 상세 모달에 "종료일이 지났습니다" Alert 표시 + 완료 처리 유도

### 1-7. 상태 태그 색상 불일치
- **문제:** PerformancePage의 `statusTag`(DRAFT=gold, ACTIVE=green)과 GoalsListCards의 `statusTagUi`(DRAFT=default, ACTIVE=blue)가 불일치
- **수정:** GoalsListCards를 PerformancePage 기준으로 통일

### 1-8. 승인 상태 raw string 노출
- **문제:** 상세 모달에서 `NOT_REQUESTED`, `PENDING` 등 영문 enum이 그대로 노출
- **수정:** `approvalStatusLabel()` 함수로 한글 라벨 + 색상 태그 적용

### 1-9. 실적 검토 라벨 혼동
- **문제:** "승인 여부" / "승인/반려" 라벨이 목표 승인 워크플로와 혼동
- **수정:** "확정 여부" / "확정/반려"로 변경

### 1-10. 히어로 "이번 달" 하드코딩
- **문제:** 분기/연간 목표에도 "이번 달 목표 달성까지"로 표시
- **수정:** "현재 목표 달성까지"로 변경

### 1-11. 승인/반려 버튼 무반응
- **문제:** `approvalRequestId`가 undefined일 때 클릭해도 아무 동작 없음
- **수정:** disabled 처리 + 경고 메시지 표시

### 1-12. DRAFT 목표 승인 요청 가능
- **문제:** 아직 진행도 시작하지 않은 초안에 승인 요청이 가능
- **수정:** `detailGoalStatus !== 'DRAFT'` 조건 추가

### 1-13. 칸반 드래그 피드백 개선
- **문제:** 모든 크로스 컬럼 이동에 동일한 단일 경고 메시지
- **수정:** 방향별 구체적 안내 메시지 분기

## 2. 추가 검토가 필요한 시나리오 (코드 외 논의 필요)

### 2-1. 가중 롤업(CHILDREN_WEIGHTED) 무시됨
- **현상:** 목표 생성 시 `rollupPolicy`로 CHILDREN_WEIGHTED를 선택할 수 있지만, 프론트엔드 `buildGoalDisplayProgressMap`은 항상 단순 평균(CHILDREN_AVG)으로 계산
- **영향:** 가중치를 설정해도 UI에 반영되지 않음
- **권장:** 백엔드 `rolledAchievementPct` 값이 내려오면 우선 사용하는 구조이므로, 백엔드에서 가중 계산을 처리하고 프론트는 서버 값을 신뢰하는 방향 권장. 또는 프론트 롤업 로직에 가중치 반영

### 2-2. 상위-하위 목표 간 정합성 검증 없음
- 하위 목표 기간이 상위 목표 기간을 벗어나도 생성 가능
- 상위 COMPLETED인데 하위가 ACTIVE로 남아 있어도 경고 없음
- 상위-하위 measureType이 달라도 허용

### 2-3. KPI 템플릿 재활성화 불가
- 비활성화(`deactivateKpiTemplate`) API만 있고, 재활성화 API/UI가 없음
- 실수로 비활성화하면 복구 불가

### 2-4. 반려 후 재제출 플로우 부재
- 실적이 반려(REJECTED)되면 해당 건을 수정/재제출할 수 없음
- 새 실적 레코드를 만들어야 하지만 이에 대한 안내 없음

### 2-5. 칸반 보드에서 owner 필터 미적용
- 리스트 뷰의 사이드패널(담당자 빠른 선택)이 보드 뷰에는 없음
- 리스트→보드 전환 시 owner 필터가 유지되지 않을 수 있음

### 2-6. 롤업 정책 필드가 리프 목표에도 필수
- 하위 목표가 없는 단일 목표에도 롤업 방식을 선택해야 함
- 사용자에게 불필요한 인지 부하

### 2-7. `goalScopeTab` 기본값 'all' vs `narrativeDefaultGoalFilters` owner 'mine'
- 탭은 "전체"로 시작하는데 필터 기본값은 "내 목표" — `effectiveFilters`에서 덮어쓰므로 동작에는 문제없으나 코드 가독성에 혼란

### 2-8. 다단계 승인 진행 상태 시각화 부족
- 3단계 승인 중 2단계까지 승인된 상태를 "승인 대기"로만 표시
- "2/3단계 승인 완료" 같은 진행 표시가 없음

### 2-9. 승인 재요청 시 이전 반려 사유 미표시
- 반려 후 재요청할 때 이전 반려 사유/코멘트를 볼 수 없어 같은 실수 반복 가능

### 2-10. 활동 내역의 실적 제출자 미표시
- 실적 이력에서 누가 제출했는지 표시하지 않음
- 팀 목표에서 여러 명이 실적을 제출하는 경우 구분 불가

## 3. 레퍼런스 UI 갭 분석 및 구현 현황

> 레퍼런스 화면: 5컬럼 테이블(제목·담당 주체·사이클·종료일·진행 상태), 사이클 필터, 총 개수 표시, 조직 사이드바 주조직 배지

### 3-1. 리스트 뷰 5컬럼 테이블 레이아웃 ✅ 구현 완료
- **이전:** 카드형 레이아웃 (제목+설명 좌측, 진행률 우측)
- **이후:** `제목 | 담당 주체 | 사이클 | 종료일 | 진행 상태` 5컬럼 그리드
- 제목 클릭으로 상세 열기, 접기/펼치기 토글, 상태 태그 인라인 표시
- 하위 목표 깊이별 들여쓰기 + 깊이 뱃지 유지

### 3-2. 사이클 배지 자동 분류 ✅ 구현 완료
- `goalCycleBadge()` 함수로 시작·종료일 기반 사이클 자동 판별
- 연간(purple), 반기(cyan), 분기(blue), 월간(geekblue), 기간형(default)
- GoalsListCards 사이클 컬럼에 Tag로 표시

### 3-3. 사이클 필터 ✅ 구현 완료
- `GoalListFilters`에 `cycles: GoalCycleKey[]` 필드 추가
- `detectGoalCycleKey()` 유틸 함수로 필터링
- 필터 팝오버에 "사이클" 다중 선택 추가
- 활성 필터 시 툴바에 태그로 표시

### 3-4. 총 개수 표시 ✅ 구현 완료
- 목표 리스트 상단에 `{N}개 목표` 텍스트 + 활성 필터 태그 표시

### 3-5. 조직 사이드바 주조직 배지 ✅ 구현 완료
- 루트 조직(parentId 없음)에 "주조직" 배지 표시

### 3-6. 진행 상태 색상 코드 ✅ 구현 완료
- 70% 이상 녹색, 40% 이상 주황, 40% 미만 빨강, 0 회색
- 프로그레스 바 + 퍼센트 + 실적/목표 수치 표시

### 3-7. 미구현 항목 (백엔드 또는 추가 기획 필요)

| 항목 | 상태 | 비고 |
|------|------|------|
| 목표 가중치 표시 및 편집 | 미구현 | 레퍼런스에 가중치 컬럼 존재 — 백엔드 `weight` 필드 활용 필요 |
| 인라인 편집 (목표명, 가중치 등) | 미구현 | 레퍼런스에서 행 클릭 시 인라인 편집 가능 — 별도 기획 필요 |
| 드래그앤드롭 행 재정렬 | 미구현 | 레퍼런스에 행 드래그 핸들 존재 — 정렬 순서 persist 필요 |
| 다중 선택 + 일괄 작업 | 미구현 | 레퍼런스에 체크박스 컬럼 존재 — 일괄 상태 변경 등 |
| 목표 유형 아이콘 분류 | 미구현 | Objective/KR/Initiative별 아이콘 구분 — `goalType` 필드 활용 |
| 사이드패널 목표 미리보기 | 미구현 | 행 클릭 시 우측 슬라이드 패널 — 현재는 모달 방식 |
